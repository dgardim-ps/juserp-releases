# Juserp

Assistente de trabalho do gabinete: leitura de autos com citação de página, degravação de audiências, base de conhecimento do gabinete e minutas para revisão.

## Instalar (Windows 10/11)

1. Baixe o instalador: **[Juserp-Setup.exe](https://github.com/dgardim-ps/juserp-releases/releases/latest/download/Juserp-Setup.exe)**
2. Execute o arquivo baixado.
   - Se aparecer **"O Windows protegeu o computador"**, clique em **Mais informações** → **Executar assim mesmo**. O aviso aparece porque o instalador ainda não tem assinatura digital.
3. Abra o **Juserp** pelo atalho na área de trabalho ou no Menu Iniciar e entre com o e-mail e a senha fornecidos.
4. Escolha a **pasta de trabalho**: a pasta onde ficam os processos, as gravações de audiência e os modelos. O assistente lê os arquivos dessa pasta e grava os resultados apenas em `_Saídas`.

## Atualizações

O aplicativo se atualiza sozinho: quando há uma versão nova, ela é baixada em segundo plano e instalada ao reiniciar (ou ao clicar em **Reiniciar agora**, na barra lateral).

## Privacidade

- Os documentos da pasta de trabalho permanecem no computador. Só são enviados ao serviço de IA os trechos necessários para cada pedido.
- Gravações enviadas para degravação e documentos da base de conhecimento ficam armazenados no Brasil (AWS São Paulo).
- O uso exige login, e o consumo de IA é registrado por usuário.
